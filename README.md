# 💱 Currency Converter

A responsive Currency Converter web application built using **HTML, CSS, and JavaScript**. This project fetches real-time exchange rates from a currency exchange API, allowing users to convert one currency into another instantly.

## 🚀 Features

- 🌍 Real-time currency conversion
- 💱 Supports multiple international currencies
- ⚡ Fetches live exchange rates using an API
- 🎯 Clean and responsive user interface
- 📱 Works on desktop and mobile devices
- 🔄 Dynamic updates without reloading the page
- ⚠️ Basic error handling for failed API requests

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- Async/Await
- Currency Exchange API

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/Shivanshi-04/Currency-converter.git
```

2. Open the project folder

```bash
cd Currency-converter
```

3. Open `index.html` in your browser.

## 🎯 How It Works

1. Enter the amount you want to convert.
2. Select the source currency.
3. Select the target currency.
4. Click the **Convert** button.
5. The application fetches the latest exchange rate and displays the converted amount instantly.
